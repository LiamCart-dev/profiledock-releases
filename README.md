# ProfileDock

ProfileDock 是 macOS 上的 Google Chrome 资料管理工具，支持资料用途备注、快速打开、插件对比、跨 Mac 迁移与元数据同步。

## 下载

- [GitHub Releases](https://github.com/LiamCart-dev/profiledock-releases/releases)
- [自建分发中心](https://releases.hczhw.com/apps/profiledock/)

系统要求：Apple Silicon Mac，macOS 14 或更新版本。下载 ZIP 后，将 ProfileDock.app 放入“应用程序”。

## 更新

在 ProfileDock 菜单或设置页选择“检查更新…”。自动检查默认关闭，可在设置中开启；下载与安装重启由用户确认。

稳定更新源：`https://releases.hczhw.com/apps/profiledock/appcast-arm64.xml`。

## 已知限制

当前版本采用 ad-hoc 签名，尚未进行 Developer ID 签名及公证，首次打开可能被 macOS 阻止。此前未包含更新功能的版本需要先手动安装一次。

本仓库用于分发安装包与 Sparkle 更新清单。
